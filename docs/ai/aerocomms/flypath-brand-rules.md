# AeroComms Landing — FlyPath Brand Rules

## Purpose

This document defines the FlyPath brand rules for the AeroComms landing page.

The landing page will live inside the FlyPath website, so it must feel like part of FlyPath first, and AeroComms second.

AeroComms should not look like a generic SaaS page or a clone of the reference website. It should feel like a premium FlyPath product focused on aviation training, ATC communication confidence and realistic pilot preparation.

---

# 1. Brand Context

FlyPath helps future pilots plan a realistic path toward becoming professional pilots.

The brand is built around:

- realistic guidance;
- no hype;
- practical aviation knowledge;
- step-by-step progression;
- clear explanations;
- trust;
- aviation experience;
- helping students avoid expensive mistakes.

AeroComms is a FlyPath training product focused on ATC communications.

It should be positioned as:

> AeroComms by FlyPath — guided ATC communication training for future pilots and student pilots.

---

# 2. Tone of Voice

Use a tone that is:

- clear;
- direct;
- premium;
- educational;
- realistic;
- confident but not exaggerated;
- useful for future pilots and student pilots.

Avoid a tone that is:

- too salesy;
- too startup-generic;
- too childish;
- too technical for beginners;
- too dramatic;
- too gaming/cyberpunk;
- full of fake urgency.

FlyPath should sound like a real pilot/training mentor explaining a serious product clearly.

---

# 3. Language Rules

Default language: Spanish.

Use English only for:

- aviation phraseology examples;
- ATC phrases;
- product labels that are intentionally in English, such as Listening, Readbacks, Phraseology, Scenarios, Progress.

Good examples:

- “Entrena tus comunicaciones ATC con confianza.”
- “Practica listening, readbacks, fraseología y escenarios guiados.”
- “Mejora tu oído para instrucciones reales de radio.”
- “Aprende a responder con estructura antes de enfrentarte a la radio real.”

Avoid:

- “Domina la radio en 7 días.”
- “Habla como un piloto profesional desde cero.”
- “La app definitiva de comunicaciones ATC.”
- “Revoluciona tu forma de volar.”

---

# 4. Positioning

AeroComms should be presented as a training tool that helps users practise before real radio pressure.

Core message:

> AeroComms helps future pilots and student pilots train listening, readbacks, phraseology and guided ATC scenarios in a structured way.

Important positioning points:

- It is educational.
- It is progressive.
- It is designed for aviation students.
- It reduces radio anxiety.
- It helps users prepare before real-world flying.
- It belongs to the FlyPath ecosystem.

Do not position it as:

- an official aviation certification;
- a replacement for an instructor;
- a replacement for real radio training;
- a guaranteed way to pass an exam;
- a fully released App Store product if that is not true;
- a finished AI ATC simulator unless that functionality exists and is ready.

---

# 5. Audience

Primary audience:

- future pilots;
- student pilots;
- PPL students;
- modular ATPL students;
- pilots preparing for first real radio exposure;
- pilots who know phraseology but lack confidence listening and replying.

Secondary audience:

- aviation English students;
- pilots preparing for training abroad;
- cadets who want extra radio practice;
- FlyPath users already interested in training tools.

The page should be understandable for beginners but still credible for someone already in flight training.

---

# 6. Visual Identity Direction

The page should combine:

- FlyPath trust;
- aviation training seriousness;
- modern product polish;
- clean SaaS/editorial layout;
- subtle motion;
- premium mockups.

Recommended feel:

- clean;
- modern;
- premium;
- light;
- spacious;
- aviation-focused;
- not cluttered;
- not gimmicky.

Avoid:

- excessive neon;
- cyberpunk radar overload;
- gaming UI;
- fake cockpit complexity;
- too many gradients;
- too many animations;
- overdesigned icons.

---

# 7. Color Direction

Use the existing FlyPath design system if available.

General direction:

- light background as primary;
- dark navy/black for text;
- FlyPath accent color for CTAs and highlights;
- subtle aviation blue accents;
- soft grey cards;
- optional dark section for contrast if consistent with current FlyPath pages.

Do not introduce a completely new color system unless necessary.

AeroComms can have a slightly more technical/product feel, but it should not visually separate itself too much from FlyPath.

---

# 8. Typography Direction

Use the typography already used in FlyPath.

Recommended hierarchy:

- large hero headline;
- short supporting paragraph;
- strong section headlines;
- clean body text;
- small eyebrow labels;
- optional italic editorial words for emphasis.

Typography should feel premium and readable.

Avoid:

- tiny text blocks;
- too many uppercase labels;
- overly technical UI copy;
- long paragraphs in hero;
- mixing too many font styles.

---

# 9. Component Style

Use existing FlyPath components where possible:

- header;
- footer;
- buttons;
- section containers;
- cards;
- badges;
- CTA blocks.

If new components are needed, make them reusable and consistent with FlyPath.

Recommended components for this page:

- hero section;
- product mockup section;
- feature card grid;
- training mode cards;
- progress section;
- audience section;
- CTA section;
- FAQ.

Cards should be:

- rounded;
- clean;
- lightly bordered or shadowed;
- spacious;
- not overloaded with text.

---

# 10. Copy Rules

## Use realistic claims

Allowed:

- “Entrenamiento guiado.”
- “Progresión paso a paso.”
- “Diseñado para futuros pilotos y student pilots.”
- “Practica antes de enfrentarte a la radio real.”
- “AeroComms está llegando a FlyPath.”
- “En fase beta.”

Avoid if not verified:

- “Miles de pilotos ya lo usan.”
- “La app número 1.”
- “Disponible en App Store.”
- “Feedback IA en tiempo real.”
- “Simulador ATC realista completo.”
- “Garantizado.”
- “Certificado.”

## Keep sections scannable

Each section should have:

- one clear idea;
- one strong headline;
- short supporting copy;
- clear visual or cards.

Do not write long marketing paragraphs.

---

# 11. CTA Rules

Primary CTA options:

- “Entrar en la beta”
- “Ver cómo funciona”
- “Quiero probar AeroComms”
- “Unirme a la lista”

For the first version, prefer:

> Entrar en la beta

Secondary CTA:

> Ver cómo funciona

Do not use:

- “Comprar ahora” unless pricing is live;
- “Descargar app” unless app download exists;
- “Empezar gratis” unless the flow exists;
- “App Store” or “Google Play” unless available.

---

# 12. Product Naming

Use:

- “AeroComms”
- “AeroComms by FlyPath”
- “AeroComms dentro de FlyPath”

Avoid:

- “FlyPath AeroComms App” if it sounds clunky;
- “ATC One” or any reference brand name;
- changing the product name.

---

# 15. Motion Rules

Motion should support the premium feel, not distract.

Allowed:

- fade in;
- slide up;
- card stagger;
- subtle floating mockups;
- light parallax;
- hover transitions;
- sticky mockup section if simple.

Avoid:

- aggressive animations;
- scroll hijacking;
- complex 3D;
- excessive radar animations;
- heavy video backgrounds;
- animations that make mobile slow.

Prioritize mobile performance.

---

# 16. Implementation Rules for Cursor

When implementing:

1. Inspect the current FlyPath project first.
2. Reuse existing styles and components.
3. Do not create a separate visual system unless necessary.
4. Build the static page first.
5. Add motion only after layout works.
6. Do not modify unrelated pages.
7. Do not change global navigation unless required.
8. Use placeholders for AeroComms screenshots if real screenshots are not available.
9. Make placeholders easy to replace later.
10. Run lint/build if available.

---

# 17. Acceptance Criteria

The AeroComms landing matches FlyPath brand if:

- it feels trustworthy and aviation-focused;
- it avoids hype;
- it uses Spanish clear copy;
- it positions AeroComms as a FlyPath product;
- it does not look like a generic AI SaaS;
- it does not overpromise features;
- it uses realistic CTA language;
- it reuses FlyPath components and spacing where possible;
- it feels premium but practical.

---

# 18. Final Direction

The page should communicate:

> AeroComms is a guided ATC communication training product inside FlyPath, built for future pilots and student pilots who want to improve listening, readbacks, phraseology and radio confidence before facing real-world ATC pressure.
